# パソコン映像クラブについて

このサーバーは、創作を一緒に楽しみたい人が集まる、作業・交流・知識共有のためのコミュニティです。

映像、音楽、CG、ゲーム、メディアアート、デザイン、プログラミングなど、ジャンルは特に限定していません。それぞれが作っているもの、気になっているもの、調べたこと、困っていることを持ち寄って、ゆるく刺激し合える場所にしたいと思っています。

完成した作品だけでなく、制作途中のものや、調べている最中のこと、まだうまく言葉にできていない興味も歓迎です。とりあえず投げてみる、誰かの投稿に反応してみる、気になる話題に乗ってみる、くらいの気軽さで使ってください。

気持ちよく使ってもらうために、お互いに最低限のモラルは意識してもらえると嬉しいです。堅苦しいルールで縛りたいわけではありませんが、相手への敬意や、外に出してはいけない情報への配慮は大切にしてください。

# サーバー独自機能について

このサーバーでは、Botを使っていくつか独自の仕組みを動かしています。普通のDiscordより少しだけ、投稿が見つけやすく、あとから追いやすくなるようにしています。

## タイムライン

<#1503666797122031677> は、サーバー内の投稿が集まるタイムラインです。

つぶやきフォーラムの投稿、質問フォーラムの新規質問、<#1503762457779376179> の新規スレッドなどが、ここに自動で共有されます。Twitter/Xのタイムラインのように、サーバー内で起きていることをざっくり眺める場所だと思ってください。

「全部のカテゴリを細かく見に行くのは大変だけど、みんなが何を投げているかは知りたい」というときに使いやすい場所です。

## つぶやきフォーラム

<#1503668971520393367> は、各自が自分のスレッドを持って、そこに自由につぶやく場所です。

自分のスレッドに投稿した内容は、タイムラインにも自動で共有されます。作業中のメモ、良かったリンク、ちょっとした感想、見てほしいものなどを気軽に投げてください。

タイムラインに流したくないメモは、投稿内に `@silent` を入れると共有されません。スポイラー画像を添付した場合は、Botが再投稿するときもスポイラーとして扱います。

他の人のスレッドに返信した場合も、タイムライン上では「誰が、誰のスレッドで投稿したか」が分かるように表示されます。

## 良い映像・良い音楽タグ

つぶやきの中では、Bot独自のタグを使うことができます。タグを付けると、タイムラインだけでなく、対応する共有チャンネルにも投稿が届きます。

たとえば、つぶやきフォーラムにこう投稿すると:

ガチで良くて
https://youtu.be/TQ2ShtsSN0A
##良い映像

この投稿は通常のタイムラインに流れるだけでなく、<#1224747669604536386> にも共有されます。同じように `##良い音楽` を付けると、<#1503813485581045851> にも共有されます。

よく使うタグは以下のとおりです。

- `##技術`
- `##tool`
- `##開発`
- `##良い映像`
- `##いい映像`
- `##良い音楽`
- `##いい音楽`
- `##飯`
- `##food`
- `##アニメ`
- `##anime`

Botが再投稿するときは、表示上は `#良い映像` / `#良い音楽` のように整えて表示します。

あとから誰かの投稿を共有したい場合は、その投稿に返信してタグだけを付けることもできます。たとえば、誰かのリンク投稿に `##技術` と返信すると、返信文ではなく元の投稿が技術共有やタイムラインに共有されます。

`## テスト` のように、半角スペースを空けてMarkdownの見出しとして使う場合は、通常の文章として扱われます。タグとして認識されるのは、対応しているタグ名と完全に一致した場合だけです。

## 質問フォーラム

各カテゴリの「質問場所」では、制作やツールに関する質問を投稿できます。個人開発カテゴリでは、Web開発、Pythonアプリ、Bot制作、ツール開発などの相談もここで大丈夫です。

質問を作成すると、Botが関連しそうなソフトや分野のロールを選ぶ案内を出します。選んだロールはタイムラインの質問カードに表示され、詳しい人に見つけてもらいやすくなります。ロールを選ばずに共有することもできます。

質問カードはタイムラインにも共有されます。誰かに見つけてもらいやすくなるので、困ったことがあれば気軽に投稿してください。

質問には、自動で `受付中` タグが付きます。解決したら、その質問スレッド内で以下のコマンドを使ってください。

`/resolve`

これを使うと、質問タイトルに `[解決済]` が付き、フォーラムタグも `解決済み` に切り替わります。タイムライン上の質問カードも、解決済みとして更新されます。

もう一度受付中に戻したい場合は、以下のコマンドで戻せます。

`/unresolve`

この操作は、質問の投稿者本人と管理者だけが実行できます。他の人が勝手に質問を解決済みにすることはできません。

## アニメ機能

アニメの話題は `##アニメ` / `##anime` を付けるか、`/anime post` を使うと作品カードを作れます。

作品カードから感想スレッドを作ったり、見た / 気になるリアクションを付けたり、自分のレビューを残したりできます。タイトル検索にはAnnictの作品情報を使い、画像が足りない場合はAniListの画像を読み取り専用で参照します。

# VCプロフィール機能について

このサーバーでは、通話に入っている人のプロフィールをBotが自動で表示します。

通話カテゴリには、それぞれ <#1503671366631559263> / <#1503671442431148083> というチャンネルがあります。誰かが通話に入ると、Botがその人の自己紹介を読み取って、現在どの通話チャンネルにいるかと一緒に表示します。人数が多いときは複数ページに分かれて、通話にいる人全員が見えるようにしています。

これによって、

- 今誰が通話にいるのか
- その人が何をしている人なのか
- XやポートフォリオなどのSNSリンクがあるか

を、通話に入る前にざっくり確認できます。

## 自己紹介を書いてください

この機能をきれいに使うために、<#1503672008930623508> に自己紹介を書いておいてください。

できれば、以下のような情報が入っていると嬉しいです。

- 名前、呼ばれ方
- やっていること
- 興味のある分野
- X / Instagram / YouTube / portfolio などのリンク
- 話しかけてほしいこと、作っているものなど

たとえば:

はじめまして、さりすです。
映像、VJ、CG、開発などをしています。
X: https://x.com/...

くらいの簡単なもので大丈夫です。

SNSリンクやポートフォリオを入れておくと、VCに入ったときに他の人があなたの活動を知りやすくなります。初対面でも話しかけるきっかけになるので、ぜひ書いておいてください。

# ロール・招待・禁止事項について

## ロールについて

このサーバーでは、必要に応じていくつかのロールを付けています。

基本的には、通常の参加者が見られる範囲を広めに取っています。ただし、関係者のみで扱う必要がある情報や、外部に出せない制作・企画に関する情報については、一部のロールを持つ人だけが見られるようにしています。

一部の分野・ソフト・知識共有系ロールは、案内されているロールパネルのリアクションから自分で付け外しできます。質問カードで通知してほしい分野を選ぶときにも、これらのロールが使われます。

ロールは、サーバー内での活動内容や関わっている企画に応じて、必要な場合に付与します。もし見えないチャンネルがあったり、必要そうな権限が足りないと感じたら、鯖主のさりすに相談してください。

## 招待について

誰かをこのサーバーに誘いたい場合は、鯖主のさりすに一声かけてください。

基本的には、創作を一緒に楽しめそうな人、制作や知識共有に前向きな人であれば歓迎です。ただし、サーバー内には関係者向けの情報や、外部に出すべきではない内容が含まれる場合もあるため、招待は一度確認を挟む形にしています。

## 禁止事項

このサーバーを気持ちよく使うために、以下のことは控えてください。

- 関係者のみに開かれた情報を外部に流出させること
- 制作中の企画、依頼、未公開情報などを許可なく外部に出すこと
- 公序良俗に反する発言や行動
- 相手への敬意や尊重を欠いたコミュニケーション
- 強い言葉で相手を攻撃したり、必要以上に不快にさせる行為
- その他、サーバーの運営が難しくなるような行動

厳しく取り締まるためというより、安心して創作や相談ができる場所にするためのお願いです。何か迷うことがあれば、勝手に判断せず、さりすか管理者に確認してください。
