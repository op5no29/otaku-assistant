# anime_quotes.json 仕様書（Codex向け）

このファイルは、Discordで「アニメ視聴本数のマイルストーンを達成したユーザーにロール付与＆DM送信」を行うBotが、DMに引用するアニメキャラクターのセリフを取得するためのデータベースです。

実装担当（Codex）は、本仕様書と `anime_quotes.json` をセットで読めば、Bot側で必要な処理が全て分かるようになっています。

---

## 1. 全体像

- **対象マイルストーン**: 10本 / 20本 / 50本 / 100本 / 300本 / 500本（計6段階）
- **各マイルストーン到達時の挙動**:
  1. 該当ロールをユーザーに付与する
  2. Botから当該ユーザーにDMを送る
  3. DM本文には、そのレベル専用に集めたセリフ集の中からランダムで1件選んだ「アニメキャラクターのセリフ」を引用する
- **DMの基本構成**: 「絵文字 + 達成メッセージ + セリフ引用 + 称賛コメント」

各レベルに 7〜12 件のセリフエントリが用意されています。Lv.500（オタク）は「複数のキャラから言われてもよい」というオーナーの要望に従い、他レベルより多めにエントリを持たせています。

---

## 2. ファイル構造（JSONスキーマ）

トップレベルは3つのキー:

```json
{
  "metadata": { ... },   // バージョン・更新日・データに関する注意書き
  "schema":   { ... },   // 構造の自己説明（このREADMEと同じ内容）
  "levels":   { ... }    // 本体データ
}
```

### `levels` の中身

`levels` のキーは閾値の数値の文字列（`"10"`, `"20"`, `"50"`, `"100"`, `"300"`, `"500"`）。値は以下の形式：

```json
"10": {
  "role_name": "アニメ視聴者 Lv.1",
  "emoji":     "🎉",
  "theme":     "始まりの一歩を祝う。続けることへの後押し。",
  "quotes":    [ ... ]
}
```

| フィールド | 型 | 説明 |
|---|---|---|
| `role_name` | string | Discord側のロール表示名と一致させる |
| `emoji` | string | DM冒頭に置く絵文字 |
| `theme` | string | このレベルでのお祝いメッセージのトーン／テーマ。Bot側で固定文面を生成する際の参考に |
| `quotes` | array of quote_object | このレベルにふさわしいセリフ集 |

### `quote_object`（quotes配列の各要素）

```json
{
  "id":           "lv10_001",
  "quote":        "諦めるなんて、絶対にしねぇ。それがオレの忍道だってばよ！",
  "character":   "うずまきナルト",
  "anime_title": "NARUTO -ナルト-",
  "official_url": "https://www.tv-tokyo.co.jp/anime/naruto/"
}
```

| フィールド | 型 | 用途 |
|---|---|---|
| `id` | string | 一意の識別子。形式 `lv{level}_{連番3桁}`。ログ／重複防止に使用可 |
| `quote` | string | 実際にDM本文に引用するセリフ |
| `character` | string | 発言キャラクター名（引用の出典表記に使う） |
| `anime_title` | string | 作品タイトル日本語（出典表記に使う） |
| `official_url` | string | 作品公式ページURL。DM内でリンクとして添えてもよい（任意） |

## 3. Bot側の処理フロー（推奨）

```
1. 視聴本数が閾値（10/20/50/100/300/500）に達したことを検知
2. JSONから levels[閾値文字列] を取得
3. levels[閾値文字列].quotes からランダムに1件選ぶ
4. 以下の構造でDMを組み立てて送信:

   {emoji} アニメ感想{閾値}作品達成！「{role_name}」ロールを付与しました。

   > {quote}
   > ―― {character}『{anime_title}』

   {テーマに沿った1〜2文の称賛コメント}
```

### 出力サンプル（Lv.10）

```
🎉 アニメ感想10作品達成！「アニメ視聴者 Lv.1」ロールを付与しました。

> 諦めるなんて、絶対にしねぇ。それがオレの忍道だってばよ！
> ―― うずまきナルト『NARUTO -ナルト-』

10本分の感想、ちゃんと記録に残ってます。ここからが本番。自分のペースで気になった作品の感想を書いていってください。
```

### 出力サンプル（Lv.500）

```
👑 アニメ感想500作品達成。「オタク」ロールを付与しました。

> 俺は、必ずシュタインズゲートを見つけてみせる！　それが！　この俺の！　選択だ！！　エル・プサイ・コングルゥ。
> ―― 岡部倫太郎『STEINS;GATE』

500本。これはもう称号です。観て、覚えて、語って、積み上げてきた記録が、サーバーの文化そのものになっています。
```

## 4. 実装上の細かい仕様

- **ランダム選択**: 単純な `random.choice(quotes)` で十分。直近で使ったセリフを覚えておいて連続で同じセリフを引かないようにするなら、ユーザーIDごとに「直前に引いたID」を保持して除外するのもあり（任意）。
- **DM送信失敗時**: ユーザーがDMをブロックしている場合は無視してロール付与だけ完了させる（Discord BotのDM送信は失敗することがある）。
- **複数同時付与**: 例えば一気に300本登録して10/20/50/100/300の全てを跨いだ場合、最終到達ロール（300）だけ付与してDMもそれだけ送るのが見栄えが良い。仕様要望はオーナーに確認。
- **称賛コメント部分**: 固定文面でよいなら `theme` フィールドを参考にレベルごとに1パターン用意。テンプレ化したものを別ファイル（`level_templates.json` など）で持つのも整理に良い。
- **データ更新**: JSONは追記しやすい構造になっているので、新しいセリフを追加したい時は該当レベルの `quotes` 配列に新エントリを追加するだけで動く。`id` の連番だけ被らないようにする。

---

## 5. データの注意点（オーナー向け）

- セリフは複数のアニメ名言まとめサイトを参照して採用しているため、原作・アニメの実テキストと細部（句読点・改行・送り仮名）で差異がある可能性があります。気になるエントリがあれば、原作該当話を確認の上書き換えてください。
- `official_url` は作品の代表的な公式ページにしてあります。シリーズで複数公式サイトが存在する場合（〈物語〉シリーズなど）は総合的なものを採用しています。リンク切れがあれば差し替え推奨。
- 同じ作品から複数レベルにセリフを採用しているケースがあります（オーナーの好み枠：エヴァ / シュタゲ / まどマギ / SAO / ノゲノラ / 無職転生 / オーバーロード）。
- 現在の収録数: 計51件。レベル別内訳 → Lv.10: 7件, Lv.20: 8件, Lv.50: 8件, Lv.100: 8件, Lv.300: 8件, Lv.500: 12件。

## 6. ミニマルな実装例（参考、Python想定）

```python
import json
import random

with open("anime_quotes.json", "r", encoding="utf-8") as f:
    db = json.load(f)

def build_dm(viewed_count: int) -> str | None:
    """視聴本数の閾値に対応するDM本文を返す。閾値でなければ None。"""
    key = str(viewed_count)
    if key not in db["levels"]:
        return None

    level = db["levels"][key]
    q = random.choice(level["quotes"])

    return (
        f"{level['emoji']} アニメ感想{viewed_count}作品達成！"
        f"「{level['role_name']}」ロールを付与しました。\n\n"
        f"> {q['quote']}\n"
        f"> ―― {q['character']}『{q['anime_title']}』\n\n"
        # 称賛コメント部分は別途テンプレ化
    )
```

これで `anime_quotes.json` の構造を理解し、Botに組み込めるはずです。
